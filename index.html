Projects

AI job search agent

Source on GitHub ↗

I got tired of scrolling job boards, so I wrote an agent that does it for me. Every morning a GitHub Actions job scrapes new LinkedIn and Indeed postings, throws out anything senior, out of area or already seen, and sends only the top 30 to Gemini for a structured assessment. I get an email by 9 AM with a fit score, the skills I'm missing and a tailored pitch for each job.

Choices I'd defend in an interview

  • The cheap, deterministic filters run before the model, so the run stays inside Gemini's free tier and still works, ranked by keywords alone, if the API is down.
  • It doesn't apply automatically. Bot-submitting breaks the job sites' terms, so the agent does the searching and writing and I click Apply.

Python · Gemini API · Pydantic · JobSpy · Pandas · GitHub Actions · pytest
