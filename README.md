# bairisettypavan1.github.io

Personal site of Pavan Bairisetty. Live at https://bairisettypavan1.github.io

Plain HTML and CSS with a few lines of JavaScript for the light/dark toggle. No build step.

## Run locally

```bash
python -m http.server 5173
```

Then open http://localhost:5173

## Deploy

Push to `main`. GitHub Pages publishes it within a minute or two.
